<analysis>**original_problem_statement:**
The user wants to build an application that generates quarterly performance reviews for restaurant employees.

PRODUCT REQUIREMENTS:
1.  The application should take an Excel spreadsheet as input.
2.  It should use an AI (initially GPT-5.2, but implemented with Emergent LLM Key) to generate a comprehensive, human-like, and HR-defensible review for each employee.
3.  The output must be a marketing-style PDF, complete with company branding (logo provided) and varied font weights.
4.  The key metrics to consider from the spreadsheet are: PPA, GPG, PPLBW, LSC Ratio, Bonus Points, and Cumulative Score. The user later specified that per-metric Tier labels (e.g., Top Performer, Meets Expectations) from the spreadsheet must be used.
5.  The final review PDF should fit on a single page and include the company logo.
6.  The PDF should also show how each employee's metrics rank against their peers.
7.  The AI-generated analysis should be concise (max 2 paragraphs).
8.  Implement a Top Performers page showing the top 10 employees for each metric and overall, with a printable report.
9.  Implement an Analytics page with graphs showing high, medium, and low benchmarks for each metric. This logic was later refined to be relative to a benchmark value.
10. Allow users to upload quarterly line graph PDFs/images, which should be appended as a second page to the employee's review PDF.
11. Add a dark theme to the application with a user-toggle.
